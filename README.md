# echo — an AI console, rebuilt

A type study from 0xleetv Studio: the interaction layer of an AI assistant,
rebuilt in the studio's own language. Mechanics studied from open public
component research (the Rare UI registry among others); every line of code here
is original. No component source was copied or shipped.

Rebuilt in this study: streaming reply with focus words, hold-to-think prompt
with a depth ring, model picker pill, inline status line, source pills,
gooey navigation, canvas fluid orb, odometer stats.

Live: https://0xleetv.github.io/echo/
